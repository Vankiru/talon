Personal set of commands for Talon Voice.

## Vim

```
# General
tree open
nerd tree
drop
undo
redo

# File
file save
file close
file force close
file open
file toggle

# Move
{number} up
{number} down
go way up
go way down

# Scroll
scroll down
scroll up
scroll middle
scroll top
scroll bottom

# Edit
(in | into) {text}
in space {text}
below
above
(line | empty) (below | down)
(line | empty) (above | up)
capital
swap (words | two)

# Search
search {text}
search drop
search next
search last

# Splits
split next
split last
split new
split close
split next close
split last close
```
